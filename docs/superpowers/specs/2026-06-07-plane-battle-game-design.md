# 飞机大战小游戏 — 设计文档

## 1. 概述

一个纵版飞机射击游戏（飞机大战），使用 **Python Flask** 作为后端提供 API 和静态文件服务，**HTML5 Canvas + Vanilla JavaScript** 作为前端渲染游戏，**JSON 文件** 存储游戏数据（最高分、统计信息等）。

## 2. 技术栈

| 组件 | 技术选型 | 理由 |
|------|----------|------|
| 后端服务器 | Python Flask | 轻量、零配置、适合小型游戏 |
| 前端渲染 | HTML5 Canvas + 原生 JS | 无需第三方库，兼容性好 |
| 数据存储 | JSON 文件 (`data.json`) | 简单可靠，无需数据库 |
| Web 协议 | HTTP (localhost) | 仅本地使用，无需 HTTPS |

## 3. 游戏机制

### 3.1 玩家

- **控制方式**：键盘方向键（↑↓←→）或 WASD 移动，自动射击
- **生命值**：5 点（屏幕左上角显示 ❤️❤️❤️❤️❤️）
- **移动速度**：水平速度较快（便于躲避敌机和子弹）
- **射击速度**：每 200ms 发射一颗子弹（快于所有敌机的射速）

### 3.2 三种敌机

| 属性 | 🟢 小型机 | 🟡 中型机 | 🔴 大型机/Boss |
|------|-----------|-----------|---------------|
| **外观** | 小三角形（绿色） | 稍大（橙色） | 大（红色） |
| **生命值** | 1 hit | 2 hits | 5 hits |
| **下落速度** | 快 | 中等 | 慢 |
| **射击间隔** | 1500ms | 1200ms | 800ms |
| **分值** | **100分** | **200分** | **500分** |
| **是否射击** | 是（向玩家方向） | 是 | 是 |

**注**：即使是最快的大型机射速（800ms）也慢于玩家射速（200ms），保证玩家有射速优势。

### 3.3 伤害机制

- **被敌机子弹击中**：生命值 -1
- **与敌机碰撞**：生命值 -1（同时敌机消失）
- **生命值归零**：游戏结束

### 3.4 敌机生成

- 敌机从屏幕顶部外随机 X 坐标生成
- 生成频率：随着游戏时间（或得分提高）逐渐加快
- 三种敌机的生成比例：小型 60% : 中型 30% : Boss 10%

## 5. API 设计

| 方法 | 路径 | 功能 | 请求/响应 |
|------|------|------|-----------|
| `GET` | `/` | 返回游戏页面 | HTML |
| `GET` | `/api/data` | 获取所有游戏数据 | `{high_score, total_games, ...}` |
| `POST` | `/api/save` | 更新游戏数据 | Body: `{high_score, total_games, ...}` → `{success: true}` |

## 6. JSON 数据格式 (`data.json`)

```json
{
  "high_score": 0,
  "total_games": 0,
  "total_kills": 0,
  "kills_by_type": {
    "small": 0,
    "medium": 0,
    "boss": 0
  },
  "last_score": 0
}
```

## 8. 前端实现细节

### 8.1 键盘控制
- **方向键/WASD**：移动玩家飞机
- 按住方向键可连续移动

### 8.2 游戏状态
- **PLAYING**：游戏进行中
- **GAME_OVER**：游戏结束，显示结算面板（本次得分、历史最高分、继续按钮）

### 8.3 碰撞检测
- 使用**矩形碰撞检测**（AABB），检测子弹与敌机、敌机与玩家、敌机子弹与玩家之间的碰撞

### 8.4 游戏界面元素
- **左上角**：生命值显示（❤️❤️❤️❤️❤️）
- **右上角**：当前得分
- **游戏结束弹窗**：本次得分、最高分、击落统计、重新开始按钮
